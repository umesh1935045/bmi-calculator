# Experiment 10: Writing Unit Tests for Flutter UI Components and Debugging

## BMI calculator implementation

The `test/experiment_10_testing_debugging/` folder contains unit tests for the BMI formula, category boundaries and invalid values, plus a widget test for the calculator screen. Run `flutter test` and `flutter analyze` from the project root.

## Why tests are under `test/`

Flutter's test runner discovers tests under the root `test/` directory. The experiment-specific subfolder keeps this experiment's test files grouped by topic.
