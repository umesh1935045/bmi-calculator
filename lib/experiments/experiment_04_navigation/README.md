# Experiment: Navigation with Navigator and Named Routes

## BMI calculator implementation

The calculator opens a result screen with `Navigator.push`, returns with `Navigator.pop`, and opens the About screen through a named route.

## Source file(s)

See the Dart files in this folder. The root application imports these components so the ten experiments form one integrated BMI calculator.

## Run / verify

From the project root:

```bash
flutter pub get
flutter run
flutter test
```
