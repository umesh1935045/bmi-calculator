# Experiment: Responsive UI with MediaQuery and LayoutBuilder

## BMI calculator implementation

`ResponsiveBmiLayout` reads screen width with MediaQuery and uses LayoutBuilder to constrain the calculator on wide screens while keeping it usable on phones.

## Source file(s)

See the Dart files in this folder. The root application imports these components so the ten experiments form one integrated BMI calculator.

## Run / verify

From the project root:

```bash
flutter pub get
flutter run
flutter test
```
