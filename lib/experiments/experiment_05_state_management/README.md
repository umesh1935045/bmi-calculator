# Experiment: State Management with ChangeNotifier and Provider

## BMI calculator implementation

`BmiProvider` stores height, weight and BMI. UI controls update the provider and Consumer rebuilds the calculator when state changes.

## Source file(s)

See the Dart files in this folder. The root application imports these components so the ten experiments form one integrated BMI calculator.

## Run / verify

From the project root:

```bash
flutter pub get
flutter run
flutter test
```
